# Kharcha – Expense Tracker

A multi-page expense tracker that runs in any browser, on phone or computer. No installs, no dependencies.

## Pages
- **Home**: monthly spending vs. budget, last 7 days chart, top categories, recent expenses
- **Activity**: all expenses grouped by date, with search and category filters
- **Add**: amount, category, note, and date
- **Insights**: category donut chart, editable monthly budget, sample data and reset options

## Features
- Data saved in the browser (localStorage), so it stays after you close the page
- Starts with sample data so the charts aren't empty (clear it from Insights)
- Follows your device's light or dark mode
- Mobile-first layout with a bottom tab bar

## Tech
HTML, CSS, and vanilla JavaScript in a single file (`index.html`). Fonts: Fraunces and Inter from Google Fonts.

## Run it
Open `index.html` in a browser.
